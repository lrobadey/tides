GRID END = 1 · DEFAULT

Shared ending

Lane i begins at boundary + offset(i) and ends at the next shared global boundary. Its audible lifetime is duration − offset(i).

GRID END = 0

Full tail

Every lane receives the full selected duration, even when delayed. It crosses the next global boundary, re-articulates at the same phase one duration later, and never overlaps itself.

03 / Technical fit

Put each responsibility at its existing seam.

Host + state

PluginProcessor

Keep APVTS construction, raw parameter atomics, playhead access, transport-discontinuity detection, state migration, and the cached host-tail value here. The processor creates one immutable controls/timing snapshot per block and does no musical scheduling itself.

Scheduling

GranulatorEngine

Own both scheduler policies. Free retains its current population scheduler. A private nested SyncState owns phase origin, pending and committed cycle settings, 64 fixed lane records, boundary progression, source anchors, and the next onset cursor.

Rendering

One grain kernel

Both schedulers feed the existing Grain array, interpolated history reader, envelope morph, stereo placement, wet normalization, feedback return, equal-power mix, and output limiter. Sync adds no parallel audio graph and no dynamic storage.

Presentation

PluginEditor

Keep controls attachment-driven and telemetry read-only. Extend GrainVisualState with explicit normalized life progress for beat-domain Sync envelopes, so TideField continues to draw measured DSP state rather than recreating timing on the message thread.

Proof

Tests + bench

Add deterministic Sync fixtures beside the current engine, processor, transport, state, telemetry, safety, and block-size tests. Extend the existing benchmark with a separate worst-case Sync scenario instead of mixing performance assertions into functional tests.

Block contract

Snapshot once, commit once.

At the start of processBlock, load every parameter once and query PositionInfo once. Validate finite BPM > 0 and finite PPQ, then pass plain values into DSP. The engine copies requested values into pending state and commits one complete cycle snapshot at a boundary; it never mixes parameter generations within one layout. Before commit, a newer mode request replaces and may cancel the pending handoff.

Musical clock

PPQ is authoritative.

All supported divisions are exact integer multiples of 1/16 PPQ. Store lattice ticks for canonical boundaries and a PPQ phase origin for deliberate division handoffs. Convert PPQ crossings to sample offsets with the current block’s BPM; do not accumulate a free-running sample clock or infer tempo between callbacks.

Hot path

Spend work only at events.

The existing renderer remains O(samples × active grains). Sync adds an O(1) next-event comparison per sample and at most O(64) work at a global boundary. Source selection, lane layout, envelope denominators, pan coefficients, and safe history limits are precomputed at boundary/onset—not inside every grain/sample calculation.

Source ownership

Store absolute anchors.

Each lane stores an absolute sourceAnchorSample selected at the boundary. Calculate the safe Tide window from actual filled history, the requested Time window, five-second ring capacity, latest lane offset, and interpolation guard. Distribute anchors with the current randomSeed and a low-discrepancy sequence keyed by boundary ordinal and lane rank. Convert to a wrapped read index only at onset. If the safe window is empty, skip that cycle; never clamp the anchor toward now.

Lifetime

Advance envelope beats, source samples.

Sync grains store onset PPQ, target lifetime in PPQ, and normalized envelope progress. Grid End uses durationPpq − offsetPpq; Full Tail uses durationPpq. Tempo changes alter the phase increment on the next block, while readPosition continues at exactly 1.0 sample per sample.

Transitions

One lane, one authoritative articulation.

Mode handoffs schedule bounded release ramps that end at the commit boundary, freeing the same 64 slots before the new layout starts. Every forced cut passes through a per-lane output smoother lasting exactly 1.0 ms, rounded to the nearest sample at the current sample rate. It stores only the lane’s last output state, creates no grain, performs no second history read, and cannot expand the voice pool.

Stopped clock

Retire voices; never invent events.

Cache the last finite playing BPM. During an intentional stop, use it only to advance the normalized envelopes of grains that were already active; boundary, onset, and source-capture cursors remain frozen. Unexpected BPM/PPQ loss while still playing instead triggers the one-millisecond safety release. Recovered clock data always re-establishes phase from host PPQ.

Legacy state

Migrate before replaceState.

JUCE restores APVTS parameters from PARAM children. Before replacing state, append any missing Sync children with explicit defaults—0, choice index 4, and 1—then preserve every existing child and randomSeed. This prevents an old preset from inheriting whatever new-control values happen to be live.

Tail + telemetry

Publish facts, not estimates.

Cache the latest valid synchronized duration in an atomic seconds value for getTailLengthSeconds, returning at least 5 seconds. Publish each grain’s normalized life progress through the existing triple-buffer exchange; the editor must not query the playhead or calculate Sync phase independently.

04 / Build

A narrow five-step vertical slice.

Parameters + host snapshot

Add stable APVTS IDs for sync, syncDivision, and gridEnd. Read BPM, PPQ, play state, and discontinuities in the processor; pass a small plain timing snapshot into DSP. Keep all work bounded and allocation-free.

Technical comment
ParameterIDs.h owns the IDs. Use AudioParameterBool for Sync and Grid End, and AudioParameterChoice for the nine divisions with index 4 as 1/8. Cache raw atomics in the processor constructor. Query AudioPlayHead::PositionInfo once per block and map it into a plain GranulatorEngine::Timing; never pass JUCE host objects into DSP.

Persistent Sync lanes

Add a Sync scheduler alongside the existing Free scheduler in GranulatorEngine. Reuse the same fixed 64-grain storage, history reader, Shape, Spread, feedback path, wet normalization, telemetry, and limiter.

Technical comment
Keep reconcilePopulation, scheduleBirths, and Free randomization unchanged behind the Free policy. Add private nested SyncState and SyncState::Lane data, with lane rank mapped directly to a grain slot. Factor only the common birth assignment into one helper; do not create a second render loop, history buffer, feedback path, or temporary voice pool.

Boundary state machine

Implement phase origin, cycle snapshots, division/density/drift/Grid End commits, full-tail re-articulation, mode handoffs, tempo-following envelope phase, and transport resets as explicit states—not ad hoc parameter branches.

Technical comment
Represent the nine divisions as integer ticks on a 1/16-PPQ lattice: {2, 3, 4, 6, 8, 12, 16, 24, 32}. Store boundary and onset targets in PPQ, derive one ppqPerSample per block, and advance a sorted lane-event cursor. Boundary work is O(N); the per-sample scheduler check stays O(1). Active Sync envelopes advance in beat space while each source read head still advances at 1× sample speed. A stopped-tail phase increment may use cached BPM, but all event cursors remain frozen.

Minimal editor seam

Add one binary Sync control, switch the visible Size readout between milliseconds and musical divisions, and add the binary Grid End control beside Drift. Keep Grid End visible but dimmed and disabled in Free mode. Put host-clock and full-tail Drift guidance in contextual tooltips only. Do not add a status line or redesign the visualizer.

Technical comment
Make the Size position one cohesive component containing two co-located attached controls: the existing millisecond slider and a discrete division slider. Toggle visibility; never detach and retarget one attachment. Add small reusable toggle components backed by ButtonAttachment, grow lowerControls to seven positions, and let an editor-owned TooltipWindow surface the two contextual explanations.

Regression ladder

Run focused scheduler/parameter/state tests, the full CTest suite, Debug and Release builds, sanitizer coverage for dense automation, then VST3/Standalone validation. DAW listening remains a separate subjective check.

Technical comment
Extend TestPlayHead with optional BPM and PPQ, and extend GranulatorEngineTestAccess rather than exposing scheduler internals publicly. Keep the existing Free block-size and deterministic-render fixtures byte-for-byte comparable. Add a Release benchmark scenario for Sync at 64 lanes; measure it separately from correctness tests.

05 / Acceptance

Prove timing, population, continuity, and preservation.

Division timing

All nine divisions and dotted ratios land sample-accurately across 1, 17, 64, changing, and non-power-of-two block sizes.

Lane geometry

Density 1 and 64, Drift 0 and 1, exact first/last offsets, even interpolation, stable lane identity, and never more than 64 active grains.

Source ownership

One Tide-selected set per boundary; delayed lanes use their exact assigned anchors. The seeded boundary/lane sequence repeats exactly across runs and block sizes. At five-second Time, maximum Drift, slow tempos, and the latest onset, source selection narrows to safe headroom and never reads overwritten audio. An empty safe window produces a silent cycle rather than a moved anchor. Sync Drift produces no source-offset or playback-speed delta.

Grid End

On: each delayed lane compresses its complete Shape envelope into its shortened lifetime and reaches silence at the shared boundary. Off: every lane lasts one full musical duration, crosses boundaries, and never overlaps itself.

Automation

Division, Density, Drift, and Grid End commit at their specified boundaries; simultaneous changes use one snapshot and the locked precedence; reversing either pending mode handoff cancels it without a stale transition; full-tail division changes cut/re-articulate without duplicates; Drift exhibits exactly one cycle of formation latency. Forced cuts traverse the one-millisecond smoother without adding a grain or history read.

Transport + tempo

Start, stop, resume, seek, loop wrap, tempo ramps represented by successive block snapshots, and starting halfway through a division all follow the locked host rules. Invalid clock from the outset schedules nothing. Stopped tails finish at the last valid BPM only while processing continues, with zero new events. Unexpected BPM/PPQ loss fades active Sync lanes; recovery re-anchors without clearing continuous history. Reported host tail covers slow synchronized durations.

State + UI

Defaults and round-trip state: Sync 0, division 1/8, Grid End 1. Loading legacy state without the new parameters supplies those defaults and preserves every existing value. Attachments reflect automation and mode-dependent Size display without changing the Free Size value; Free mode leaves Grid End visibly dimmed, disabled, and in place. Sync and Grid End tooltips explain host-clock and full-tail Drift timing without a status line.

Existing sound

Free-mode renders remain unchanged. Tide range, Shape, Spread, Feedback, Mix, output ceiling, non-finite containment, and telemetry continue to pass their existing contracts.
